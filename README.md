# WFL-ASR Models

Pretrained [WFL-ASR](https://github.com/MLo7Ghinsan/WFL-ASR) models for phoneme labelling of singing in different
languages. The models are attached to the [Releases](https://github.com/Megageorgio/WFL-ASR-Models/releases) of this
repository.

WFL-ASR itself (code, training and inference): https://github.com/MLo7Ghinsan/WFL-ASR
